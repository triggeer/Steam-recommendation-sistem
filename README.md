Steam Recommendation System
Веб-приложение для персонализированных рекомендаций игр в Steam, основанных на игровой библиотеке пользователя и предпочтительных тегах.

Алгоритм анализирует библиотеку Steam пользователя и генерирует список игр, которые могут соответствовать его игровым предпочтениям. Оно сочетает сходство игровых тегов с пользовательскими рейтингами для обеспечения баланса между релевантностью и качеством

Особенности:
- Персонализированные рекомендации — генерация рекомендаций игр на основе библиотеки Steam пользователя и времени, проведенного в игре.
- Сходство по тегам — представление игр с использованием взвешенных тегов и сравнение их профилей с помощью косинусного сходства.
- Ранжирование рекомендаций — объединение оценок сходства с пользовательскими рейтингами для определения очерёдности релевантных и высоко оцененных игр.
- Интеграция данных Steam — получение информации об играх из API Steam и SteamSpy.
- Информация об играх — отображение доступной информации, включая описание, теги и ссылку на игру в Steam

Stack:
- Язык: C#
- Framework: ASP.NET Core MVC (.NET 10)
- ORM: Entity Framework Core
- БД: PostgreSQL
- API: Steam Web API, Steam Store API, SteamSpy API

Алгоритм:
1) Сбор информации о играх пользователя
2) Формирование вектора тегов пользователя на основе игр и наигранного в них времени
3) Сравнение вектора пользователя с играми из БД путём косинусного сходства
4) Присваивание каждой игре рейтинга с учётом полученной информации о пользователе и оценкам игры
5) При формировании списка снижаем балл игры за сходство с уже выбранными играми, чтобы список был разнообразным
6) Создание списка из 30 наиболее подходящих игр, которые ещё не были предложены пользователю
